# 额外姿势备选 / Additional options

这些是 Ying 额外要求的姿势备选，之后使用时再选择；不会替换已确认的八张图。原素材包、总览和八张选定版本均保持原样。生成与确认仍按一张一张进行。

- Photography：已确认额外备选为 [photography-seated-steps-v2.png](photography-seated-steps-v2.png)，Ying："好的，下一张"。v1 保留为未确认历史版本；此前姿态曾获赞许（"这张很好，正是我喜欢的！"），之后因相机方向问题要求修正（"等等，相机屏幕你再看一下是不是不太对"）。v2 保留人物、坐姿和场景，镜头朝外/下方、背面屏幕朝人物。尚未选入网站，也不替换原八张图。
- Data & Analytics：已确认额外备选为 [data-analytics-seated-computer-v3.png](data-analytics-seated-computer-v3.png)，Ying："这张可以"。人物自然看电脑办公，不看观众；网页观者只看到显示器背面。v1/v2 仍为未确认历史候选；此备选不修改原已确认站姿图。

每张生成图有独立提示词和 JSON 来源记录；总索引见 `manifest.json`。所有候选 selected_for_site=false、replaces_approved=false、website_integrated=false。

## Data & Analytics 工作朝向

[data-analytics-seated-computer-v1.png](data-analytics-seated-computer-v1.png) 和 [data-analytics-seated-computer-v2.png](data-analytics-seated-computer-v2.png) 保留为未确认的历史候选。较早的反馈 "可以面朝我，不用看到电脑屏幕，和墙上的内容重复了" 产生了面朝观者的 v2；该人物朝向已被最新要求取代："看电脑办公，不用看观众"。

当前修正版要让人物的头部、躯干和双手自然朝向键盘与显示器，呈现真正使用电脑工作的状态，不与观者对视。"看电脑办公，不用看屏幕" 中的不展示屏幕，是指网页观者只看到显示器平整的背面；人物仍看向自己的电脑。图表仅留在墙上，避免电脑重复一套图表。这一工作朝向已体现在确认的 v3 中。
