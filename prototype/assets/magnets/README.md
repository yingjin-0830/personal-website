# Original Travel keepsakes

These 12 SVG files are exact exports of the existing `window.YingMagnets.svg(id)` artwork from `prototype/magnet-art.js`. The wooden frame, illustration geometry, colours, original lettering and viewBoxes are unchanged. `manifest.json` records source and file hashes.

The collection buttons load these as decorative images, with accessible destination names on the buttons. This keeps lettering inside the souvenirs as image content rather than competing UI labels. The destination index uses its visible city name as its accessible name; its number and plus sign are decorative.

All artwork was checked against its original viewBox before export; external images use `object-fit: contain` to preserve the original SVG fit. Detail dialogs can continue using the existing inline artwork API.
