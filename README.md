# Ying Jin — personal website

A personal portfolio with Professional and Personal paths, an animated avatar, experience cards, and a travel magnet collection.

## Versions

- `main`: the original warm, illustrated character version.
- `editorial-flat`: an independent experiment with adult-proportion flat fashion illustration and editorial magazine typography.

Both versions keep the same résumé draft and site structure so the visual approaches can be compared. Professional details remain drafts pending Ying's verification.

## Run locally

No package installation or build step is required.

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory prototype
```

Open http://127.0.0.1:4173/ .

The implementation, character assets and generation prompts are in `prototype/`. Screenshots used for local QA are ignored by Git. Uploading source to GitHub does not enable public website hosting automatically.
